# contempt/composer-plugin

[![CI](https://github.com/contempt-framework/composer-plugin/actions/workflows/ci.yml/badge.svg)](https://github.com/contempt-framework/composer-plugin/actions/workflows/ci.yml)

Composer 2 plugin: package manifest discovery, declarative recipes and contempt.lock ownership.

> This repository is a **read-only split** of the Contempt monorepo.
> Issues and pull requests belong in
> [contempt-framework/contempt](https://github.com/contempt-framework/contempt).

## Installation

```bash
composer require contempt/composer-plugin
```
